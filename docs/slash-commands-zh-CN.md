# pi 斜杠命令中文对照

在输入框敲 `/` 会弹出当前会话可用的命令，可以用方向键选择、输入过滤。

## 模型与设置

| 命令 | 中文说明 |
|---|---|
| `/settings` | 打开设置菜单 |
| `/model [provider/model]` | 选择模型，可带 `服务商/模型ID` 直接定位 |
| `/thinking [level]` | 设置思考等级 |
| `/scoped-models` | 配置 Ctrl+P 循环切换时的模型范围 |
| `/login [provider]` | 添加服务商登录或密钥 |
| `/logout` | 移除服务商登录 |
| `/llama` | 管理 llama.cpp 路由上的本地模型 |

## 会话与上下文

| 命令 | 中文说明 |
|---|---|
| `/new` | 开始新会话 |
| `/resume` | 切换到另一个已保存的会话 |
| `/name [name]` | 设置会话显示名，省略则显示当前名 |
| `/session` | 查看当前会话的信息与统计 |
| `/tree` | 打开会话树导航 |
| `/fork` | 从某条历史用户消息处分叉出新会话 |
| `/clone` | 在当前位置复制当前会话 |
| `/compact [instructions]` | 压缩上下文，可附加自定义指令 |
| `/import <path>` | 导入并续接一个 JSONL 会话 |

## 导出与分享

| 命令 | 中文说明 |
|---|---|
| `/copy` | 复制最后一条助手消息 |
| `/export [path]` | 导出为 HTML 或 JSONL |
| `/share` | 上传会话并返回查看链接 |
| `/bug [description]` | 生成一份给 pi 开发者的私有问题报告 |

> 导出或分享前先检查会话内容：里面可能有提示词、工具参数、命令输出、文件内容和对话中暴露的凭据。

## 运行时与项目

| 命令 | 中文说明 |
|---|---|
| `/trust` | 保存项目信任决定，供后续 pi 进程使用 |
| `/reload` | 重新加载键位、扩展、技能、模板、主题和上下文文件 |
| `/hotkeys` | 查看当前生效的快捷键 |
| `/changelog` | 查看更新日志 |
| `/quit` | 退出 pi |

## 资源带来的命令

- 扩展可以注册自己的命令，带自己的参数补全
- 每个提示模板直接用模板名作为命令
- 技能在开启技能命令后以 `/skill:名字` 出现
